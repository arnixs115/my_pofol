# BR-B 제출 기록

## 결과물

실행 묶음: `protein-go-explorer.zip` (비밀번호 없음). 모두 압축 해제 후 `protein-go-explorer/index.html`을 엽니다. 상세 실행·확인은 README.md를 따릅니다.

앱 한 문장: 단백질 기능 분석을 배우는 연구자와 학습자가 길이와 GO 주석의 관계를 탐색할 때, 이 앱은 논문의 약한 양의 상관관계와 원자료의 분포를 이용해 입력 길이의 위치와 구간별 주석 통계를 보여 줍니다.

사용자가 할 일: ① 단백질 길이 입력 ② 전체·BP·MF·CC GO 통계 탐색 ③ 민감도 분석 결과와 연구 한계 확인.

## 짧은 확인 방법

`index.html`에서 350 입력 → 41.26%, 250–499 aa, 7,235개 확인 → MF 선택 → 중앙값 2.0·상관계수 0.2592 확인 → Gene ID 기준 선택 → ρ=0.2013, n=19,031·제외 규칙 확인. 빈칸 입력 후 오류 안내, 350 aa 예시 선택 후 복구까지 확인하면 기능 검증 통과입니다.

## AI와 나의 판단 3줄

1. AI에게 맡긴 일: 논문·CSV 대조, 통계 재계산, 정적 웹앱 구현, 오류 처리·테스트·실행 묶음과 증거 정리.
2. 내가 직접 판단한 일: BR-A 최종 확정을 확인하고, 논문·원본 CSV에서 검증된 통계만 사용하도록 정했으며 단백질 길이 입력·GO 탐색·연구 해석을 앱 범위로 정했다.
3. AI 제안을 따르지 않은 일: 따르지 않은 제안은 없습니다. 제안이 제가 정한 세 가지 기능과 검증된 통계 사용 원칙에 맞았기 때문입니다. (사용자가 직접 확인한 문장)
