# 데이터 출처

이 앱의 관측 데이터는 UniProt Consortium의 UniProtKB에서 수집한 공개 인간 Reviewed 단백질 데이터(릴리스 2026_03, 수집일 2026-10-30)에 기반합니다.

UniProtKB 데이터에는 [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)이 적용됩니다. [UniProt 라이선스 안내](https://www.uniprot.org/help/license), [운영기관의 데이터 안내](https://www.expasy.org/resources/uniprotkb)를 참고하세요.

원분석: [protein-go-research](https://github.com/arnixs115/protein-go-research). 이 앱에서는 원자료의 숫자형 5개 열만 남기고 길이순으로 정렬했습니다. 구간별 분포·누적비율·GO 구간 통계를 추가 계산했습니다. 데이터 제공기관이 앱을 보증한다는 뜻은 아닙니다.

논문과 원분석 결과의 저작권은 원권리자에게 있습니다. 이 문서는 앱 코드 자체에 별도의 오픈소스 라이선스를 부여하지 않습니다.
