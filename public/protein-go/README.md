# Protein GO Explorer · BR-B

단백질 기능 분석을 배우는 연구자와 학습자가 길이와 GO 주석의 관계를 탐색할 때, 논문의 약한 양의 상관관계와 원자료의 분포를 이용해 입력 길이의 위치와 구간별 주석 통계를 보여 주는 정적 웹앱입니다.

반영 논문: **인간 단백질의 아미노산 서열 길이와 Gene Ontology 기능 주석 개수의 관계에 관한 탐색적 분석** (2026-11-02).

## 실행: 설치 없이 열기

1. 비밀번호 없는 `protein-go-explorer.zip`을 새 폴더에 **모두 압축 해제**합니다.
2. `protein-go-explorer/index.html`을 Chrome 또는 Edge 등 최신 브라우저에서 엽니다.
3. 인터넷·계정·API 키·환경변수·추가 설치 없이 세 가지 기능을 사용합니다. ZIP 미리보기 안에서 실행하지 마세요.

브라우저의 로컬 파일 정책 때문에 실행이 제한되면 Python 3가 설치된 컴퓨터에서 앱 폴더를 기준으로 `python -m http.server 8000`을 실행한 후 브라우저 주소창에 `http://localhost:8000`을 입력합니다. 일반 실행에는 Python이나 Node.js가 필요하지 않습니다.

## 1분 확인: 사용자가 할 일 세 가지

1. **길이 입력:** `350`을 입력하고 ‘분포에서 확인하기’를 누릅니다. `41.26%`(8,429/20,431), `250–499 aa 구간`, 단백질 7,235개가 표시되면 통과입니다. 전체 GO 중앙값은 8.0, 사분위 범위는 5.0–15.0, 평균은 11.83입니다.
2. **GO 통계 탐색:** GO 범주를 MF로 바꿉니다. 같은 7,235개에서 중앙값 2.0, 평균 2.77이 표시되고 MF 상관계수 0.2592 행이 강조되면 통과입니다. ‘그래프의 정확한 수치 보기’에서 표도 확인합니다.
3. **연구 해석:** ‘비교할 분석 조건’을 ‘단일 Gene ID별 accession 1개’로 바꿉니다. ρ=0.2013, n=19,031과 제외 조건·해석 한계가 나오면 통과입니다. 이 선택은 논문 결과 비교용이며 위의 구간 통계는 전체 데이터 기준입니다.

추가 확인: 빈칸·음수·소수·문자·1,000,001은 안내 메시지를 표시하고 이전 결과를 숨깁니다. 이후 `350 aa` 예시를 누르면 정상 복구되어야 합니다. `34351`은 관측 범위 밖 안내와 누적비율만 표시하고 구간 통계를 만들지 않아야 합니다. ‘현재 탐색 결과 TXT 저장’은 입력과 결과·해석 한계를 담은 텍스트를 저장합니다.

## 데이터와 계산

- 공개 출처: [연구 저장소](https://github.com/arnixs115/protein-go-research), [분석 CSV](https://github.com/arnixs115/protein-go-research/blob/main/protein-go-research/data/processed/full_20261030/protein_go_dataset.csv), [원논문 PDF](https://arnixs115.github.io/my_pofol/documents/research-paper.pdf).
- UniProtKB 릴리스 2026_03, 수집일 2026-10-30, 인간 Reviewed primary accession 20,431개. 원 CSV와 공개 저장소의 Git blob SHA가 일치함을 확인했습니다.
- `data/observations.csv`에는 길이·전체 GO·BP·MF·CC의 숫자형 5개 열만 있습니다. accession, 단백질명, 유전자명과 Gene ID는 제외했습니다. 길이순으로 정렬했으며 관측치는 모두 유지합니다.
- `data.js`는 같은 관측치와 검증된 연구 결과를 로컬 파일에서도 읽도록 묶은 파일입니다. `tests/core.test.cjs`가 CSV와 정확히 일치하는지 확인합니다.
- `data/correlation_results.csv`, `data/sensitivity_results.csv`, `data/descriptive_statistics.csv`는 원분석 결과 파일 그대로입니다. 해시는 `evidence/statistics-verification.json`에 있습니다.
- 원자료에서 평균·표본 SD·중앙값·사분위수·범위와 상관계수 6개를 독립 재계산했습니다. CI는 해시가 검증된 기존 2,000회 부트스트랩 결과의 2.5/97.5 백분위수를 다시 계산했습니다. 새 부트스트랩 전체 실행은 하지 않았고, p값도 독립 재계산하지 않았습니다. 전체 GO의 p값은 원분석의 문자열 `2.210109e-339`를 보존했습니다. 부동소수점 칸의 0은 실제 p=0을 뜻하지 않습니다.
- 앱의 길이 구간은 1–99, 100–249, 250–499, 500–999, 1,000–1,999, 2,000–34,350 aa입니다. 경계는 앱 설계자가 정한 기술통계 구간이며 논문의 모델·생물학적 임계값이 아닙니다. 마지막 구간은 넓으므로 동질 집단으로 해석할 수 없습니다. 그래프는 밀도가 아닌 **구간별 개수**를 표시합니다.
- 누적비율 = `입력 길이 이하 관측치 수 / 20,431 × 100`; 동률을 포함합니다. 분위수는 선형 보간입니다. 관측 범위 2–34,350 aa 밖에는 구간 통계를 제공하지 않습니다.

## 해석의 범위

ρ=0.2705는 약한 양의 단조 연관성입니다. GO 개수는 실제 기능 수가 아니며, GO=0도 기능 부재가 아닙니다. 이 앱은 개별 단백질의 주석 수·기능을 예측하지 않습니다. 범주 간 ρ 차이는 별도로 검정하지 않았습니다. Gene ID 기준 분석의 감소는 누락·복수 매핑 제외와 중복 축소가 함께 반영된 결과입니다. CI와 p값은 관측 행의 교환가능성·독립성을 가정하는 모형 기반 탐색 추론입니다. 다른 시점·생물종에 대한 일반화, 인과 주장, 교란 통제는 하지 않았습니다.

## 구성과 검증

- `index.html`, `style.css`, `app.js`: 화면과 사용자 동작
- `core.js`: 입력 검증·구간 계산·분위수·히스토그램, 외부 의존성 없음
- `data/`, `data.js`: 숫자형 관측치와 연구 보고값
- `tests/core.test.cjs`: Node.js 18 이상에서 `node --test tests/core.test.cjs`
- `evidence/`: 통계 대조, 실제 브라우저 확인, 제출 기준과 미완료 항목
- `SUBMISSION.md`: 확인 방법, 판단 3줄, 동료 피드백 상태

개발 테스트에만 Node.js가 필요합니다. 키와 환경변수는 사용하지 않습니다. 외부 글꼴·분석 도구·추적·로그인·서버 통신·localStorage·쿠키를 사용하지 않으며 입력값은 브라우저 메모리에만 존재합니다. 보고서 저장은 사용자가 누를 때만 로컬 TXT로 생성됩니다. 소스·CSV·JSON의 주요 키·연락처 패턴 검사와 공개 파일 내용 검토 결과는 증거 파일에 기록합니다. 패턴 검사만으로 모든 비밀값이나 개인정보를 탐지할 수 있는 것은 아닙니다.
